# ⚡ Installation


Clone repository:

```bash
git clone https://github.com/Aman1803ami/Aman1803ami.github.io.git
```

Move into project:

```bash
cd Aman1803ami.github.io
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build:

```bash
npm run build
```
